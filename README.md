# smart-campus-app
A Smart Campus Management System project developed as part of an IT Management program.

## Project Overview

Smart Campus App is a proposed mobile platform designed to improve communication, resource management, and student services within a university environment.

## Objectives

- Centralized student services
- IT support ticket management
- Room booking system
- Timetable management
- Push notifications

## Technologies

- Mobile Application
- REST API
- Relational Database
- Cloud Infrastructure
